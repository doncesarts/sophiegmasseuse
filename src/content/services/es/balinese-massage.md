El masaje balinés combina distintas técnicas de varias culturas que el pueblo balinés fue adaptando con el tiempo para crear un estilo propio (de China, India, Java y Suecia).

Este masaje combina movimientos largos, suaves y presión ligera en puntos específicos. Relaja los músculos, calma la mente y ayuda a recuperar el equilibrio interior.
Se utiliza aceite esencial de flor de frangipani para profundizar la sensación de relajación.
